# 行为与兼容性

本包为 1.0.0 本地发布候选版，包含 SwiftUI 原生界面、Python 后台、只读本地网页及合成数据测试
接收者可将解压后的 `codex-usage-widget` 文件夹交给 Codex，要求读取 `SKILL.md` 后在新目录构建
若要注册成常驻 Skill，可按接收者的 Skill 安装流程操作；同名 Skill 已存在时先确认，不直接覆盖

## 原生浮窗的当前行为

- 顶部显示账号额度、重置时间、实时积分及可用重置卡；未知数值不冒充零
- 重置卡使用按钮有禁用和可用状态，需要再次确认；无卡、状态过期或账号不可核对时不新发起消费
- 每轮任务以“聊天名称：本轮消息”命名，未命名聊天以消息命名；标题单行省略
- 模型、档位与发起时间放在第二行，进行或完成耗时与本轮 Token 放在第三行，只有 Token 数字加粗；Ultra 使用紫色
- 子 Agent 按名称收在对应主任务下面，关联成功的本轮用量汇总到主任务，同一轮不重复计数
- 展开状态保留列表、子 Agent 展开和历史加载，收缩状态只显示首个任务的三行信息，最小化状态显示额度与最近运行轮次的 Token
- 优先显示正在运行的任务，多个运行任务按发送时间取最新，没有运行任务才回退最近记录
- 默认宽度 300 点，最小宽度 260 点，最小高度 240 点，最大宽度按屏幕约三分之一限制，最大高度 669 点，并受屏幕可用区域限制
- 额度更新时间在左下角，右下角为无底纹的“回到默认位置”按钮；点击后保持当前尺寸，回到 Codex 窗口右下角并恢复跟随停靠
- 非运行任务整行不透明度为 85%；子 Agent 按自己的运行状态淡化，不叠加父任务的淡化，最小化形态仅淡化任务标识和用量
- 边缘与四角支持拖动尺寸；缩短至紧凑形态时折叠任务列表，窄屏下简化辅助文字，保留用量信息
- 默认停靠 Codex 窗口右下方，右、下边距各 12 点；手动拖动后不强行吸回，关闭隐藏后重新打开恢复默认停靠
- 展开与收缩切换固定底边和右边，收缩时上边缘向下移动
- 仅在已识别的聊天页显示，设置页、其他非聊天页及其他软件自动隐藏，返回聊天恢复；三种形态规则一致，手动关闭仍保持隐藏
- 页面识别需单独为浮窗授权 macOS 辅助功能，只读取控件结构与输入区域固定名称，不读取正文，不控制聊天，不保存页面内容
- 圆角为 16 点；拖动使用屏幕坐标，拖动期间暂缓界面快照更新，松手后刷新和切换形态
- 雷达高概率数字有强调样式，具体阈值以源码为准；详情通过独立弹出区显示

尺寸是这一版的默认配置，不是官方 UI 规范；其他显示缩放比例和多屏环境仍需在接收者电脑上验收

## 已知限制

1. 仅为 macOS 源码版，需要支持当前 SwiftUI 源码的系统和 Xcode 命令行工具，以及 Python 3；未验证 Windows、Linux 或其他 macOS 版本
2. 浮窗是独立应用，目前跟随的官方应用标识为 `com.openai.codex`；不是官方内置组件，也不附着到输入框内部
3. 四边拖动本身可用，但非激活浮窗上悬停时，系统光标仍可能是普通箭头，这一问题未解决，不能宣称完整的原生光标体验
4. 源码依赖当前本机 Codex CLI 的额度及重置卡接口，以及 `~/.codex/state_5.sqlite` 和本机会话日志结构；这些结构可能随官方更新改变
5. 如果接收者 CLI 不支持重置卡接口，不能承诺可用，应保持未知或禁用并转去官方界面核对，不擅自升级或替换用户 CLI
6. 多条追加消息可能共用一个执行轮次，日志无法可靠拆分时只展示这一轮合并值，不能承诺每次发送都独立计量
7. 云端、其他设备、缺失日志或缺少父子关联标识的记录无法保证完整统计；额度是账号级，本轮 Token 是本地可见记录，两者不等价
8. 不做自动历史清理，`logs/` 会增长，首次历史扫描和大量长期记录可能影响性能；清理必须另行确认
9. 页面识别依赖官方输入区域的辅助功能描述，当前中文界面已实测；其他语言或官方界面变更仍需适配，识别失败或没有权限时保守隐藏，菜单栏“授权聊天页识别…”可进入授权流程

## 可重复的隔离检查

在新复制出的源码目录运行 Python 测试和构建，不在 Skill 原件构建
原生逻辑测试可编译到新建临时目录执行，不启动统计后台、不读取账号、不使用重置卡

```sh
widget_test_dir=$(mktemp -d)
swiftc -D WIDGET_TESTS src/Widget.swift src/ChatPageVisibility.swift src/test_widget_visibility.swift -o "$widget_test_dir/TestVisibility" -framework Cocoa -framework SwiftUI
"$widget_test_dir/TestVisibility"
```

`--probe` 是可选的本机只读页面识别诊断，需该调用进程已有辅助功能权限，仅打印识别结果和耗时，不打印输入框内容

## 本地网页不是原生浮窗的等价替代

后台运行时，`http://127.0.0.1:49672/` 提供附属只读页面，只有旧版基础额度和原始轮次明细，不包含原生三形态、主子汇总与重置卡使用等全部能力
它不是实际嵌入官方侧栏的组件，不应把网页按钮或文字当作已与原生界面同步
该服务只绑定本机，但本机其他程序仍可能读取摘要和短标题，不要暴露给局域网或公网
点击浮窗关闭按钮只隐藏界面，后台仍运行；从菜单栏退出工具才会停止后台和本地网页更新

## 分享包与原使用者版本的有意区别

- 套餐按账号返回的 `planType` 映射：Plus 1X、PRO 10X、PRO 20X、PRO 25X，分别对应 plus、prolite、pro、promax；倍率文字是项目约定的别名，不是官方返回的实时额度倍率，不用于计费或额度换算
- 移除仅适用于原使用者某几天的个人额度建议下限
- 合成测试中的余额、标题和标识符改为示例，不随包提供真实任务数据
- 补充可执行 CLI 的 PATH 回退；实际启动路径仍需在目标机检查，尤其是 Finder 启动与终端环境不同时
- 构建脚本遇到同名应用会停止，不覆盖已存在的应用

公开包不分发提取自官方应用的图标文件；构建时仅在接收者本机查找官方应用的 `chatgptTemplate@2x.png`，缺失时回退通用芯片图标，不代表 OpenAI 官方产品背书或商标授权

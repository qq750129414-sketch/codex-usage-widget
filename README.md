# Codex 用量小窗｜Codex Usage Widget

[简体中文](README.md) | [English](README.en.md)

一边在 Codex 聊天里工作，一边看当前任务的实时用量，不用切换窗口

贴合聊天界面的 Mac 用量小窗，查看本轮 Token、子 Agent 用量和剩余额度，离开聊天页自动隐藏

这是个人制作的第三方小工具，不是 OpenAI 官方产品，也不会修改 Codex 本体

## 怎么安装

把当前仓库地址复制给你 Mac 上的 Codex，再加一句：

> 请从 https://github.com/qq750129414-sketch/codex-usage-widget 安装 Codex 用量小窗 Skill，并按 SKILL.md 安装、启动浮窗

不用自己研究代码，也不用先下载压缩包
Codex 会检查环境、读取仓库里的安装说明并在你的电脑上构建应用；首次缺少必要组件时，按提示确认即可

**目前仅支持 Mac，需要已登录的 Codex 桌面应用、Python 3 和 Xcode 命令行工具**
当前版本在 macOS 26.4.1 上构建验证，其他系统版本尚未逐一验证

中英文介绍均已提供，当前浮窗界面仍为中文；系统里的应用名称暂为“Codex用量浮窗”

### 开启辅助功能权限

允许“Codex用量浮窗”使用辅助功能权限，用来判断你是否在聊天页面

入口：macOS **系统设置 → 隐私与安全性 → 辅助功能**
也可以点菜单栏 **◉ 用量 → 授权聊天页识别…**，按系统提示开启

没授权时，后台和菜单栏可能已经启动，但浮窗暂时不显示
升级后如果开关显示开启却仍提示未授权，需要为新版本重新授权，不要反复启动多个浮窗

## 能做什么

- 查看剩余额度、重置时间、积分余额和重置卡数量
- 查看每一轮任务的 Token，而不是把整段聊天累计都堆在一起
- 子 Agent 收到主任务下面，能关联到本轮的用量一起汇总
- 拖动位置、拉宽拉窄、拉长拉短
- 额度更新时间在左下角，右下角的定位按钮可一键回到默认位置，保留当前大小
- 已结束或已终止的任务整行稍微淡化，让正在运行的任务更容易分辨
- **展开、缩小、最小化**三种形态：看完整列表、只看一个任务，或只留一条小横条
- 正在运行的任务优先显示，多个任务取最新发起的；没有运行任务时显示最近一条
- 进入设置、离开聊天页或切到其他软件时自动隐藏，回到聊天页再出现

## 重置雷达，可选

想看“24 小时重置概率”，在微信搜索 **“重置雷达”小程序**，按小程序当前说明获取自己的 **API Key**，再让 Codex 帮你配置

它接入第三方重置雷达服务 `api.tangka.online`，展示预测、服务状态和公共重置记录，**不是 OpenAI 官方预测，不保证你的账号会重置，也不会帮你自动重置**

不需要就不配置，额度、积分、任务 Token 等基础功能照常使用
API Key 在你本机交互输入并保存到钥匙串，不要发到 GitHub、聊天或截图里
小程序的申请条件或收费以其当时说明为准，本项目不附送密钥

## 套餐怎么显示

程序自动读取当前登录账号的套餐类型，再按本项目的约定显示：

| 实际套餐 | 面板名称 |
| --- | --- |
| Plus | Plus 1X |
| Pro 100 | PRO 10X |
| Pro 200 | PRO 20X |
| Pro 500 | PRO 25X |

**X 是本项目约定的显示别名，不是后台返回的实时额度倍率，也不参与任何额度或 Token 计算**
其他套餐显示实际类型；识别不到时显示未知，不默认套用 Pro

## 还有几点要知道

- 辅助功能权限只用于识别页面，不读取输入框正文，也不代替你操作聊天
- 用量统计会另外读取本机 Codex 会话日志和任务元数据，并在安装目录保存私人用量记录；截图分享前注意任务标题
- “本轮 Token”包含模型调用实际处理的输入、缓存输入和输出，不等于新生成的字数，也不等于积分账单；云端、其他电脑和缺失日志不保证完整
- 重置卡只有你主动点击“使用”并再次确认才会消耗，0 张时不能使用
- 点叉号只是隐藏；从菜单栏“◉ 用量”可以找回，选择“退出用量统计”才会退出后台
- 官方软件更新可能影响日志格式、页面识别或额度接口，不保证永久兼容
